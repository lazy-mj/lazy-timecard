# 참여율 대조 도구 (timecard)

> **사내 업무지원 도구**\
PMS(내부망)와 IRIS의 **인건비 참여율(타임카드)을 사람별·월별로 자동 대조**해주는 웹 도구입니다.
설치·로그인 없이 브라우저에서 바로 쓸 수 있고, 서버 없이 전부 내 PC 안에서 처리됩니다.

## 🌐 바로 사용하기
**GitHub Pages** 👉 [lazy-mj.github.io/lazy-timecard](https://lazy-mj.github.io/lazy-timecard/)

---

## ✨ 주요 기능

- 🪄 **PMS·IRIS 파일 자동 인식** — 두 파일을 한 번에 끌어다 놓으면 어느 쪽인지 알아서 구분해요
- 🏢 **ETRI 참여자만 골라서 대조** — IRIS의 다른 공동기관 연구자는 자동으로 제외
- 📅 **사람 × 월 표로 한눈에** — 엑셀처럼 한 사람당 PMS 줄 · IRIS 줄, 값이 다른 달은 두 칸이 함께 빨갛게
- 🗂 **여러 과제를 한 번에** — 파일을 섞어 올려도 참여자 이름이 가장 많이 겹치는 PMS·IRIS 파일끼리 자동으로 짝지어요 (선택창에서 바꿀 수 있음)
- 🔀 **두 가지 기준으로 비교** — 실행과제 기준(PMS 월별 인건비 참여율) / 협약 기준(PMS 협약사업 참여기간·참여율)을 탭으로 전환
- 🧩 **실행계정이 여러 개인 과제** — 한 IRIS 과제를 PMS 실행계정 여러 개(예: 26XX0010, 26XX0020)로 나눈 경우, 계정별 엑셀을 모두 올리면 같은 IRIS에 묶어 사람별·월별로 합산해 대조해요 (과제번호 끝 두 자리만 다르면 같은 과제로 인식, 칸에 마우스를 올리면 계정별 내역)
- 📆 **참여기간도 확인** — 참여율이 같아도 시작일·종료일이 다르면(중도입사 등) "기간 확인"으로 표시. PMS 날짜는 실행과제 참여기간 문구에서 읽어요
- 👤 **과제 책임자는 항상 맨 위**
- 🧮 **연평균 입력도 인정** — IRIS에 기간 하나로(연평참) 넣었어도 참여기간과 평균 참여율(참여율 합 ÷ 참여 개월수)이 같으면 "연평균 일치"
- ◐ **한 달 일부만 참여한 기간 표시** — 예: 08/18~08/31. 마우스를 올리면 날짜가 보여요
- ⚠️ **놓치기 쉬운 것들 경고**
  - 동명이인(같은 이름이 한쪽에 2명 이상, 참여한 달이 겹칠 때) → 자동 대조하지 않고 확인 필요로 표시. 재입사로 새 개인번호를 받아 두 줄이 된 경우(달이 안 겹침)는 한 사람으로 합쳐요
  - 이름 표기가 다른 경우(PMS '마이클' / IRIS 전체 이름) → 한쪽 이름이 다른 쪽에 포함되면 같은 사람으로 보고 안내
  - IRIS 수행구분 '수행종료'인데 PMS엔 참여 중
  - 학생 구분 불일치: PMS 직급이 학생연구원(위촉연구원·UST학생연구원·학연학생)인지와 IRIS 참여구분 '학생'이 서로 다를 때 (동·하계 연구연수생은 학생연구원 아님, 이름 아래 학생 태그)
  - 미등록: PMS나 IRIS 한 곳에만 있는 사람 (IRIS 다른 기관에 같은 이름이 있으면 함께 안내)
- 💾 결과는 **요약 시트 + 과제별 월별대조 시트로 나뉜 엑셀 파일로 다운로드** — 화면처럼 테두리, 판정 색, 다른 달 칸 색까지 들어가요

## 🚀 사용 방법
1. **파일 업로드** — PMS 참여인력 엑셀과 IRIS 참여연구자 엑셀을 함께 끌어다 놓기 (여러 과제를 한꺼번에 올려도 돼요)
2. **대조할 과제 확인** — 자동으로 짝지어진 PMS ↔ IRIS 파일이 맞는지 확인
3. **대조 실행**
4. **결과 확인** — 빨간 칸과 아래 안내 문구 확인, 필요하면 [결과 다운로드]

### 어디서 다운로드하나요?
- **PMS(ETRIware) 참여인력** : 과제관리 > 사업관리 > 실행과제관리 > 실행계획서관리 > 과제조회 후 더블클릭(실행과제마스터) > 참여인력 탭 > 우측상단 [엑셀변환]
- **IRIS 참여연구자** : IRIS R&D업무포털 > 과제수행 > 협약변경 > (승인통보)협약변경신청 > 과제조회(책임자명, 과제명 등) > 연구개발과제명 앞 네모 버튼 > 통합과제 팝업 > 수행정보 탭 > 연차별수행정보 탭 > 참여연구원 탭 > 좌측에서 당해 연구개발기간 선택 > 참여연구원 참여시작일 확인 후 우측상단 [엑셀]

## 📏 판정 규칙

| 판정 | 뜻 |
|---|---|
| 일치 | 모든 달의 참여율이 같음 (◐ 부분 참여월은 참여율 값만 비교) |
| 연평균 일치 | 달마다는 다르지만, IRIS가 기간 1개이고 참여 시작·끝 달과 평균 참여율이 같음 |
| 불일치 | 참여율이 다른 달이 하나라도 있음 (몇 개월 다른지 표시) |
| 확인 필요 · 기간 확인 | 참여율은 같지만 참여 시작일·종료일이 다름 — 중도입사·퇴사 등 (해당 달 노란색) |
| 확인 필요 | 동명이인, 또는 한 달 안에 참여율이 둘 이상인 달이 있음 |
| IRIS 미등록 / PMS 미등록 | 한 곳에만 있는 사람 (이름으로 짝을 찾지 못함) |

사람은 **이름**으로 맞춥니다 (PMS 개인번호와 IRIS 국가연구자번호는 서로 이어지는 값이 없어서). IRIS 계상비율은 **현금**만 봅니다.

## 🔒 보안 관련

- 네트워크 요청 코드가 전혀 없고, `Content-Security-Policy`로 외부 통신을 브라우저 단에서 차단해뒀습니다
- 업로드한 파일이나 결과는 어디에도 저장되지 않으며 새로고침하면 모두 사라집니다
- 다만 정적 페이지 특성상 소스 코드(대조 로직)는 누구나 열람 가능합니다 — 데이터만 비공개이며 코드 자체는 공개된 도구입니다

## 🛠 기술 스택

순수 HTML / CSS / JavaScript + [SheetJS(xlsx)](https://sheetjs.com/)로 만든 정적 웹앱입니다. 결과 엑셀의 테두리·색 서식은 [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style)(Apache-2.0)로 씁니다 (파일 읽기는 SheetJS, 쓰기만 xlsx-js-style). 공통 디자인·헤더는 [lazy-office](https://github.com/lazy-mj/lazy-office)의 `shared/`를 불러 씁니다.

```
index.html           메인 페이지
css/style.css        스타일
js/
  core/              그리드 유틸 · 날짜/기간 펼치기 · 대조 엔진
  systems/           PMS · IRIS 어댑터 (RCMS는 여기에 파일 하나 추가)
  ui/                상태 · 렌더링 · 엑셀 내보내기
  main.js            이벤트 바인딩 · 초기화
  vendor/            xlsx 라이브러리 (읽기: SheetJS 0.20.3 / 서식 있는 쓰기: xlsx-js-style 1.2.0)
tests/smoke-test.js  판정 규칙 테스트 (가짜 데이터) — node tests/smoke-test.js
```
