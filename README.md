# 참여율 대조 도구

> **사내 업무지원 도구**\
PMS(내부망)와 IRIS·RCMS의 **인건비 참여율(타임카드)을 사람별·월별로 자동 대조**해주는 웹 도구입니다.
설치·로그인 없이 브라우저에서 바로 쓸 수 있고, 서버 없이 전부 내 PC 안에서 처리됩니다.

## 🌐 바로 사용하기
**GitHub Pages** 👉 [lazy-mj.github.io/lazy-timecard](https://lazy-mj.github.io/lazy-timecard/)

---

## ✨ 주요 기능

- 🪄 **PMS·IRIS 파일 자동 인식** 
- 🏢 **ETRI 참여자만 골라서 대조**
- 📅 **사람 × 월 표로 한눈에** 
- 🗂 **여러 과제를 한 번에** 
- 📸 **RCMS는 화면 캡처로**
- 🧩 **실행계정이 여러 개인 과제** 계정별 엑셀을 모두 올리면 같은 IRIS에 묶어 사람별·월별로 합산해 대조
- 📆 **참여기간도 확인** — 참여율이 같아도 시작일·종료일이 다르면(중도입사 등) "기간 확인"으로 표시.
- 🧮 **연평균 입력도 인정** — IRIS에 기간 하나로(연평참) 넣었어도 참여기간과 평균 참여율(참여율 합 ÷ 참여 개월수)이 같으면 "연평균 일치"
- ◐ **한 달 일부만 참여한 기간 표시** — 예: 08/18~08/31. 마우스를 올리면 날짜가 보여요
- ⚠️ **놓치기 쉬운 것들 경고**
  - 동명이인/이름 표기가 다른 경우/IRIS 수행구분 '수행종료'인데 PMS엔 참여 중/학생 구분 불일치/미등록
- 💾 결과는 **요약 시트 + 과제별 월별대조 시트로 나뉜 엑셀 파일로 다운로드**

## 🚀 사용 방법
1. **파일 업로드** — PMS 참여인력 엑셀과 IRIS 참여연구자 엑셀을 함께 끌어다 놓기 (여러 과제를 한꺼번에 올려도 돼요)
2. **대조할 과제 확인** — 자동으로 짝지어진 PMS ↔ IRIS 파일이 맞는지 확인
3. **대조 실행**
4. **결과 확인** — 빨간 칸과 아래 안내 문구 확인, 필요하면 [결과 다운로드]


## 📏 판정 규칙

| 판정 | 뜻 |
|---|---|
| 일치 | 모든 달의 참여율이 같음 (◐ 부분 참여월은 참여율 값만 비교) |
| 연평균 일치 | 달마다는 다르지만, IRIS가 기간 1개이고 참여 시작·끝 달과 평균 참여율이 같음 |
| 불일치 | 참여율이 다른 달이 하나라도 있음 (몇 개월 다른지 표시) |
| 확인 필요 · 기간 확인 | 참여율은 같지만 참여 시작일·종료일이 다름 — 중도입사·퇴사 등 (해당 달 노란색) |
| 확인 필요 | 동명이인, 또는 한 달 안에 참여율이 둘 이상인 달이 있음 |
| IRIS 미등록 / PMS 미등록 | 한 곳에만 있는 사람 (이름으로 짝을 찾지 못함) |

사람은 **이름**으로 맞춥니다. IRIS 계상비율은 **현금**만 봅니다.

## 🔒 보안 관련

- 외부 서버로 데이터를 보내는 코드가 없고, `Content-Security-Policy`로 외부 통신을 브라우저 단에서 차단해뒀습니다 (RCMS 글자 인식 엔진·한글 데이터를 이 사이트에서 불러오는 것만 허용)
- 업로드한 파일이나 결과는 어디에도 저장되지 않으며 새로고침하면 모두 사라집니다
- 다만 정적 페이지 특성상 소스 코드(대조 로직)는 누구나 열람 가능합니다 — 데이터만 비공개이며 코드 자체는 공개된 도구입니다

## 🛠 기술 스택

순수 HTML / CSS / JavaScript + [SheetJS(xlsx)](https://sheetjs.com/)로 만든 정적 웹앱입니다. 결과 엑셀의 테두리·색 서식은 [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style)(Apache-2.0)로 씁니다 (파일 읽기는 SheetJS, 쓰기만 xlsx-js-style).

```
index.html           메인 페이지
css/style.css        스타일
js/
  core/              그리드 유틸 · 날짜/기간 펼치기 · 대조 엔진
  systems/           PMS · IRIS 어댑터 (RCMS는 여기에 파일 하나 추가)
  ui/                상태 · 렌더링 · 엑셀 내보내기
  main.js            이벤트 바인딩 · 초기화
  vendor/            xlsx 라이브러리 (읽기: SheetJS 0.20.3 / 서식 있는 쓰기: xlsx-js-style 1.2.0)
tests/smoke-test.js  판정 규칙 테스트 (가짜 데이터) — node tests/smoke-test.js
```
